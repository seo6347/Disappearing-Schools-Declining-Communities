SCENE 01

통학구역을 통한
집계구–초등학교 연결

스크롤하며 살펴보기 ↓

01 / 통학구역

A초의 통학구역부터
출발합니다

각 초등학교에는 법적으로 정해진 통학구역이 있습니다.
해당 통학구역에 거주하는 학생들은 지정된 공립초등학교에
가게 됩니다.

통학구역 배정은 주로 공립초등학교를 기준으로 하며, 국립이나 사립 등은
별도의 모집이나 지원 절차를 따르므로 분석 대상에서 제외하였습니다.

02 / 집계구 경계

서로 다른 두 경계를
겹칩니다

집계구는 인구규모, 사회 경제적 동질성(주택유형,자가), 땅의 형상 등을 고려하여 구축된 최소 통계 집계구역입니다.

통학구역과 집계구는 별도의 기준으로 나뉘기 때문에
두 경계가 서로 일치하지 않을 수 있습니다.

03 / 학령인구 추정

나이별 인구로
초등학생 수를 추정합니다

SGIS 자료에서는 집계구 인구를 학년별로 제공하지 않아
5~9세와 10~14세 인구에 각각 3/5을 곱해,
초등학생 수를 추정했습니다.

모든 연령에 각 인원이 균등하게 분포한다고 가정하여 3/5를 곱합니다.

5~9세 인구× 3/5
10~14세 인구× 3/5

두 값을 더해 초등학생 수 추정

04 / 집계구 계산 예시

K집계구의 초등학생 수는
약 36명입니다

5~9세 20명, 10~14세 40명에 각각 3/5을 곱합니다.

20명 × 3/5 = 12명40명 × 3/5 = 24명12명 + 24명 = 36명

K집계구는 계산 원리를 보여주는 별도 예시입니다.

05 / 대표점으로 연결

집계구 안에
대표점을 찍습니다

대표점이 A초 통학구역 안에 있으면,
해당 집계구의 추정 학생 수를 A초에 연결합니다.

이를 통해 해당 집계구에 거주하는 초등학생들이 A초에 통학한다고 추정합니다.

QGIS의 ST_PointOnSurface로 집계구 내부 대표점을 계산합니다.
연결선은 학생 배정 관계이며 실제 통학 도로가 아닙니다.

06 / 통학구역 밖 대표점

구역 밖 대표점은
A초에 연결하지 않습니다

통학구역에 걸쳐 있는 집계구라도 대표점이 밖에 있으면
A초에 연결하지 않습니다.

통학구역과 집계구는 서로 다른 기준으로 나뉘기 때문에
구역 밖 대표점은 다른 학교의 통학구역에 속할 수 있습니다.

07 / 공동통학구역

두 학교에 함께 연결되는
집계구도 존재합니다

공동통학구역의 집계구를 두 초등학교에 모두 연결하고,
각 학교로 균등하게 간다고 가정합니다.

100명 → A초 50명 + B초 50명

만약 예시와 달리 3개 학교의 공동통학구역이면
각 초등학교에 1/3씩 간다고 가정하는 방식입니다.

08 / 실제 재학생 수로 보정

학교의 실제 학생 수에
맞춰 보정합니다

초기 집계구별 초등학생 수는 3/5를 곱한 추정치이므로
실제 학교 재학생 수에 맞추어 보정합니다.

따라서 보정 후 특정 초등학교를 다니는 집계구들의 초등학생수를
모두 합산하면 해당 초등학교 학생수와 같습니다.

A초 50명 → 20명 / B초 50명 → 80명

학교별 실제 재학생 수에 맞춰 보정하므로
집계구의 보정 후 합계는 초기 추정 인구와 다를 수 있습니다.

SCENE 02

연결된 세 학교
후보 만들기

스크롤하며 살펴보기 ↓

01 / 분석 대상

조건에 맞는 학교를
남깁니다

전국 6,302개교에서 공립·소규모·본교 등의 조건을 적용하면 2,513개교, 학생분포 연결을 확인하면 2,503개교가 남습니다.

02 / 간선 연결 조건

같은 교육지원청 안에서만
학교를 연결합니다

교육지원청이 다른 A초와 E초는 연결하지 않습니다.
통합 후보는 같은 교육지원청 안에서만 만듭니다.

실제 초등학교의 통폐합 행정은 주로 교육지원청이 관할합니다.

03 / 모든 학교쌍

네 학교 사이의
모든 연결을 그립니다

같은 교육지원청 내의 모든 학교를 간선으로 연결합니다.

이 간선은 직선거리 관계를 뜻하며 실제 통학 도로가 아닙니다.

04 / 학교 간 거리

모든 간선마다
직선거리를 계산합니다

A–B 9km, A–C 14km, A–D 12km, B–C 8km, B–D 5km,
C–D 6km입니다.

05 / 10km 기준

10km 이하인 연결만
남깁니다

10km를 초과하는 모든 간선을 제거합니다.
따라서 14km인 A–C, 12km인 A–D 간선을 제외합니다.

10km는 민감도 분석 이후 설정된 값이며,
너무 먼 거리의 학교가 서로 통합되는 것을 방지하기 위함입니다.

06 / 세 학교 후보

연결된 세 학교를
하나의 후보로 묶습니다

K1　A–B–C

K2　A–B–D

K3　B–C–D

남은 간선을 따라 세 학교가 서로 이어지는 모든 조합을 만듭니다.

K1이나 K2와 같이 가운데 학교를 거쳐 연결될 수도 있고,
K3와 같이 세 학교가 모두 직접 연결될 수 있습니다.
이 단계에서는 후보 간 학교 중복을 허용합니다.

SCENE 03

학교 수용력 검증과
극단적인 경로 제외하기

스크롤하며 살펴보기 ↓

01 / 세 가지 통합학교안

세 학교 중
어느 학교를 남길까요?

A-B-C라는 1개의 군집 후보에는 A초·B초·C초를
각각 남기는 세 가지 통합학교안이 있습니다.
어느 학교로 통합할지를 결정해야 최종 시뮬레이션 대상이 확정됩니다.

02 / 학교 수용력

학교는 통합할 모든 학생을
수용할 수 있어야 합니다

A,B,C초의 전체 재학생 수의 합은 150명입니다.
이 때 A초는 최대 140명까지만 수용가능하므로
A초로 통합할 수 없어 A초 통합학교안은 제외됩니다.

수용력 = 일반교실 수 × 28명

과밀학급 기준 28명을 적용하였습니다.

03 / 실제 도로경로

극단적인 경로를 제외합니다

폐교 예정학교에서 통합중심학교까지의 자동차 직행 경로를 검토합니다.
산악 지형과 같이 직선거리는 짧아 후보로 선정되었으나
실제 이동경로가 너무 길어지는 경우를 제외하였고,
해상교통수단이 포함된 경우 현실적으로
통폐합이 어렵다고 판단하여 제외하였습니다.

해상교통수단이 포함된 경로, 최대 이동시간 80분 초과, 또는 최대 이동시간 40분 초과이면서 최대 우회비율 3배 초과인 통합학교안을 제외합니다.

실제 분석에서는 산악지형 여부가 직접 나오진 않으며 이해를 돕기 위한 예시입니다.

SCENE 04

겹치지 않는
최종 군집 선정하기

스크롤하며 살펴보기 ↓

01 / 겹치는 후보

한 학교를
여러 군집에 넣을 수 없습니다

K1(A-B-C), K2(A-B-D), K3(B-C-D)는 모두 학교 B를 공유합니다.
실제로 선택할 군집끼리는 학교가 겹치지 않아야 합니다.

한 학교가 여러 군집에서 동시에 통폐합이 되는 것은 불가능합니다.
따라서 최종 군집 하나에만 포함되도록 중복되지 않게 각 군집을 선정해야 합니다.

02 / 정수최적화

세 가지 기준을
차례로 적용합니다

중복해서 학교가 선택되지 않도록 최종 군집을 선택하는 기준입니다.

접근시간 점수는 통합학교안별 두 학교의 최대 도로시간 중 최솟값이며,
학생별 통학시간이 아닙니다.

03 / K3 선정

중복되지 않게
하나의 군집을 선택합니다

현재 예시는 후보들이 모두 겹치므로
최종적으로 군집 하나만 선택됩니다.

단, 현재 선택된 것은 군집의 구성으로,
어디로 통합할지 통합학교안은 정해지지 않았습니다.

SCENE 05

최종 시뮬레이션 대상
결정하기

스크롤하며 살펴보기 ↓

01 / 통합학교안

남은 통합학교안을
비교합니다

이렇게 선정된 K3 군집은 앞선 Scene 3의 수용력 검증으로
C초로의 통합학교안이 제거되었으므로 B초와 D초 중 어디로 통합시킬지를 결정해야 최종 시뮬레이션 대상이 확정됩니다.

만약 통합학교안이 하나만 남았다면 별도의 비교없이 해당 통합학교안으로 확정됩니다.

02 / 학생 통학경로

현재 학교까지의 경로와
통폐합 후 경로를 비교합니다

기존에 다니던 학교 경로와 통폐합 후 새로 다니게 될 학교 경로를 비교합니다.

실제 분석은 Naver Directions API(경로 계산을 위한 111,762회 API요청)를 사용하여 단순 직선거리가 아닌 출발지에서 목적지까지의 실제 자동차 직행 경로를 계산하였습니다.

예시에서는 쉬운 이해를 위해 편의상 집계구 1개만 표시하였습니다.

03 / 평균 추가 부담

늘어나는 통학부담이
작은 쪽을 선택합니다

평균 추가 통학 부담을 최소화하는 방식으로 최종 통합학교안을 확정합니다.

Σ(학생 가중치 × 늘어난 이동시간) ÷ 전체 학생 가중치

통학 시간이 줄어드는 경우는 늘어난 이동시간을 0으로 계산하였습니다.

해당 지표는 학생 수를 고려한 1인당 평균 추가 통학시간을 의미합니다.

04 / D초 통합학교안

D초로 통합하는
시나리오가 확정됩니다

D초가 최종 통합중심학교로 선택되고 B초와 C초는 폐교됩니다.

05 / 전국 결과

전국 720개 군집의
통폐합 시나리오

이러한 방식으로 전국을 대상으로 총 720개 군집의 통폐합 시나리오를 확정했습니다.

720개 군집 · 통합중심학교 720개교 · 폐교 대상 1,440개교최종 참여학교 2,160개교

왼쪽 그림의 전국 지도는 예시가 아닌 실제 분석 결과입니다.
