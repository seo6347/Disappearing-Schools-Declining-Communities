# 작은학교 통폐합 분석 과정 스크롤리텔링

팀 프로젝트 **「학교가 사라진 다음」의 분석 방법론을 설명하기 위해 제작한 독립적인 시각화 모듈**입니다. 복잡한 분석 코드를 읽지 않아도 학교와 학생분포가 연결되고 통합 대상이 결정되는 과정을 이해할 수 있도록 구성했습니다.

## 설명 범위

Scene 1~5에서 집계구 기반 학생분포 추정·보정, 학교 간 연결망과 3개교 후보 생성, 수용력·도로 접근성 검증, 비중복 군집 최적화, 최종 존치학교 선정을 설명합니다. 모달 안에서 스크롤에 따라 SVG 도식과 설명문이 함께 바뀌며, 마지막에는 전국 분석 결과를 보여줍니다.

## 사용 기술과 구성

HTML, CSS, JavaScript, SVG, GSAP·ScrollTrigger 3.13.0을 사용합니다. 빌드나 백엔드는 필요하지 않습니다.

- `index.html`: 기존 `preview.html`을 활용한 독립 실행 페이지
- `method.html`, `method.css`, `method.js`: 모달·설명문·스크롤 애니메이션
- `preview.js`: HTML 조각 로드와 실행 버튼 연결
- `data/`, `img/`: 설명용 예시 JSON, Scene 1~5 SVG, 최종 지도 이미지
- `vendor/`: 로컬 GSAP 라이브러리와 [출처·라이선스 안내](vendor/THIRD-PARTY.md)

## 실행 방법

저장소 루트에서 다음 명령을 실행한 뒤 [독립 실행 페이지](http://127.0.0.1:8000/method-scrollytelling/)를 열고 **분석 과정 살펴보기**를 누릅니다.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

HTML·JSON·SVG를 `fetch`로 불러오므로 파일 더블클릭(`file://`) 대신 HTTP 서버를 사용합니다. 기존 QA 기능은 `method-scrollytelling/?qa=1`에서 사용할 수 있습니다.

GitHub Pages에는 저장소 루트를 게시하면 됩니다. 페이지 경로는 `/Disappearing-Schools-Declining-Communities/method-scrollytelling/`이며 모든 자산은 상대경로로 불러옵니다. 현재 데모 배포는 예정 상태입니다.

## 예시 데이터와 실제 분석

`data/method_example_fixture.json`의 A~D초, 집계구, 거리·시간과 군집 선정은 분석 원리를 보여주기 위한 **가상 사례**입니다. 실제 학교나 학생의 개별 경로 자료가 아닙니다. 마지막 전국 결과 수치·지도는 기존 분석에서 산출한 결과를 보여주는 것으로, 가상 사례의 결과와 구분해야 합니다. 이 모듈은 전국 분석을 다시 실행하거나 결과를 새로 계산하지 않습니다.

전체 분석 코드, 실제 결과와 가정·한계는 [상위 저장소 README](../README.md)를 참고하세요. 이 폴더에는 시각화에 필요한 예시와 자산만 포함하며, 전국 원자료·API 수집 결과·개발 중 QA 로그와 캡처는 포함하지 않습니다.
